# qqmemory 命名约定

项目英文名与 GitHub 仓库统一为 `qqmemory`，中文应用名保留“空间记忆”。

- GitHub：`https://github.com/FFantta/qqmemory`（原 `FFantta/space-memory`）。
- 新构建 ZIP：`qqmemory-<版本>-<平台>.zip`。
- GitHub Actions 工作流：`qqmemory desktop releases`，Windows 产物：`qqmemory-windows-x64`。
- 官网：`https://qqmemory.com/`。

兼容旧版本的名称不能直接全局替换：已有官网 ZIP 地址、云端地址、SQLite/媒体目录、会话 Cookie 名、环境变量和 macOS bundle ID 需要保留或提供迁移。历史运维日志保持当时名称，以便追溯。
