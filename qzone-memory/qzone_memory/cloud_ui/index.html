用手机 QQ 扫码，在云端整理本轮可取得的说说与互动，直接预览或下载离线档案。

开始之前

这个入口会将 QQ 登录会话交给云端进程，并在服务器暂存取得的内容。它与“数据只在本地”的桌面版不同。

  • 登录凭据只在任务内存中使用，结束或取消后清除。
  • 结果仅在当前浏览器中可访问，最多保留 1 小时，也可以立即删除。清除浏览器 Cookie 后将失去访问入口。
  • 体验版最多约 2 分钟文字扫描、12 张图片；不是完整深度找回，不保证找回全部历史或原图。
  • 服务重启会中断正在运行的扫码与采集，请重新开始。免费服务闲置后会休眠，重新打开可能需等待约一分钟；休眠或重启会清空结果，请生成后立即下载。

不输入 QQ 密码。请核对 QQ 内显示的授权信息，再确认登录。
