先回来一点。

用手机 QQ 扫码，在云端整理本轮可取得的说说与互动，直接预览或下载离线档案。

开始之前

这个入口会将 QQ 登录会话交给云端进程，并在服务器暂存取得的内容。它与“数据只在本地”的桌面版不同。服务器位于新加坡，因此 QQ 可能提示登录地点为“新加坡”；请核对这是否对应你刚刚发起的扫码。

  • 登录凭据只在任务内存中使用，结束或取消后清除。
  • 结果仅在当前浏览器中可访问，每轮结束后最多保留 1 小时，也可以立即删除。清除浏览器 Cookie 后将失去访问入口。
  • 每轮约 20 分钟文字扫描、30 分钟总采集，启用深度历史断点。不按 12 张或 300 张截断；边扫描边下载可用图片，可实时预览文字和已保存照片，最后按体积打包。高清检查可在之后单独发起，不保证取得原图。每任务图片临时容量约 512 MiB，可用空间不足时可能更早停止，不保证找回全部历史或原图。

不输入 QQ 密码。请核对 QQ 内显示的授权信息，再确认登录。

等待扫码

保存二维码

使用另一台设备上的 QQ 扫码最直接。同一部手机可尝试在 QQ 扫一扫中从相册识别，是否支持需以实际 QQ 为准。二维码过期后会自动刷新。

预览归档下载单文件 HTML下载 HTML 与图片 ZIP

小档案可下载嵌入图片的单文件 HTML；大档案按约 64 MiB 原图体积分包，大小不同是正常的，不是两个版本。第 1 包包含 HTML、首批图片和报告，后续包包含剩余图片，缺一会少图。解压合并后的目录为 index.html、media/（照片、头像、表情）、其他/（报告与说明）。请下载全部 ZIP，合并各包同名的“空间记忆”及 media 文件夹，再打开 index.html。Mac 若解压为多个编号文件夹，请将各包 media 中的文件合并到第一包。继续任务会生成新的完整分包，不能只取最后一包。未取得的图片仍保留提示。
